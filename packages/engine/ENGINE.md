# autoedit: ادیتور خودکار ویدیوی کوتاه (فاز ۱، مرحله ۱)

یک ویدیوی خام عمودی می‌گیره و طبق یک **نقشه‌ی ادیت** (فایل JSON)، ریلز ادیت‌شده تحویل می‌ده.
کارهایی که انجام می‌ده:

- حذف مکث‌ها و زوم خودکار روی صورت
- زیرنویس فارسی کلمه‌به‌کلمه
- موشن‌گرافیک
- تعویض پس‌زمینه و قرار دادن عناصر پشت سر گوینده
- افکت صوتی و موسیقی

نقشه‌ی ادیت فعلاً دستی نوشته می‌شه. در مرحله‌ی ۳، Claude API اون رو خودکار می‌نویسه.

```
ویدیوی خام ─► analyze ─► (کارگردان: نقشه‌ی ادیت) ─► validate ─► render ─► qc
```

## نصب

**با Docker (پیشنهادی برای سرور):**
```bash
docker build -t autoedit .
docker run --rm -v "$PWD/examples:/data" autoedit render test2_plan.json -j 7
```

**بدون Docker:** پیش‌نیازها Python 3.10+، ffmpeg و npm (فقط برای دانلود مدل‌ها) هستن.
```bash
pip install ".[stt-local]"
bash scripts/fetch_assets.sh ./assets   # فونت وزیرمتن، مدل جداسازی آدم، مدل گفتار
export AUTOEDIT_ASSETS=$PWD/assets
```

## دستورها

| دستور | کار |
|---|---|
| `autoedit analyze video.mp4 -o out_dir` | ورودی‌های لازم برای کارگردان رو می‌سازه (توضیح در بخش بعد) |
| `autoedit validate plan.json [--fix] [--json]` | خطاهای نقشه رو قبل از رندر پیدا می‌کنه (توضیح در بخش بعد) |
| `autoedit render plan.json -j N` | رندر موازی با N پردازه |
| `autoedit qc output.mp4 plan.json` | یک برگه‌ی تصویری از همه‌ی لحظه‌های گرافیکی برای بازبینی سریع |
| `autoedit join out.mp4 a.mp4 b.mp4 … [--json]` | چند ویدیو رو به ترتیب به یک ویدیوی عمودی می‌چسبونه. ویدیوی افقی روی نسخه‌ی تارِ خودش قرار می‌گیره و ویدیوی بی‌صدا سکوت می‌گیره. مرز هر ویدیو در `out_clips.json` ذخیره می‌شه. |
| `autoedit check-source video.mp4` | می‌گه ویدیو باید عمودی بشه یا نه (`{"normalise": true}` برای ویدیوهای افقی یا مربعی) |

### خروجی `analyze`
- متن زمان‌دار. اول با تشخیص صدای انسان (Silero VAD) بررسی می‌شه کسی حرف می‌زنه یا نه. اگه حرفی نباشه، تبدیل گفتار به متن اجرا نمی‌شه. جمله‌هایی که Whisper روی سکوت یا موسیقی «از خودش می‌سازه» هم حذف می‌شن.
- بخش `speech`: داشتن صدا، چند ثانیه صحبت و بازه‌های صحبت
- مکث‌ها (ویدیوی بدون صدا هم کار می‌کنه و سکوت حساب می‌شه)
- مسیر حرکت و فاصله‌ی گوینده
- ثابت یا متحرک بودن دوربین
- یک تصویر در هر ثانیه

### بررسی‌های `validate`
**خطا (رندر رو متوقف می‌کنه):**
- بازه‌ی برش بیرون از ویدیو یا خالی
- مدت خروجی بالای ۹۰ ثانیه
- گرافیک یا افکت یا صدای ناشناخته

**هشدار:**
- زیرنویس‌های هم‌پوشان
- گرافیک یا زیرنویسی که داخل برش افتاده و هیچ‌وقت دیده نمی‌شه
- گرافیکی که از کادر بیرون زده
- گرافیک روی زیرنویس یا روی یک گرافیک دیگه
- بیش از ۴ ثانیه بدون تغییر تصویری
- نبودن قلاب در ۱.۵ ثانیه‌ی اول

با گزینه‌ی `--fix` موارد ساده خودکار اصلاح می‌شن.

## نقشه‌ی ادیت (خلاصه)
یک نمونه‌ی کامل: `examples/test2_plan.json`

- `timeline`: بخش‌های ویدیوی خام به ترتیب نمایش. قابلیت‌ها:
  - `role: cold_open` برای شروع با صحنه‌ی آینده
  - `reverse` برای پخش برعکس
  - `zoom: "auto"` برای زوم خودکار روی صورت
  - `transition_in`: یکی از whip، flash، zoom_in یا glitch
- `captions`: زیرنویس‌ها با زمان، به‌علاوه‌ی کلمه‌های تأکیدی
- `graphics`: موشن‌گرافیک‌ها. فهرست انواع در `autoedit/motion.py`:
  - kinetic_text، speech_bubble، stamp، app_card، ring_counter
  - viewfinder، no_human، nle_timeline، burst، warning_sign
  - pill، vhs_rewind، live_voice
- `effects`: sky_fly، jungle، sun، dinosaur_walk
- `sfx`، `zoom.punches`، `grade`، `audio.music`

همه‌ی زمان‌ها بر حسب ثانیه‌ی ویدیوی خام‌اند. استثنا عناصری‌اند که `role` دارن؛ زمان اون‌ها از شروع همون بخش حساب می‌شه.

## جداسازی آدم از پس‌زمینه
مدل سریع MediaPipe ماسک اولیه رو می‌سازه. اگه دوربین ثابت باشه، از خود ویدیو تصویر «اتاق خالی» ساخته می‌شه. این تصویر سه کار انجام می‌ده:
- تکه‌های اتاق رو که اشتباهی جزو آدم حساب شدن حذف می‌کنه (مثلاً جسمی هم‌رنگ لباس).
- دست‌های در حال حرکت رو که مدل جا انداخته اضافه می‌کنه.
- تغییر نوردهی خودکار گوشی رو جبران می‌کنه.

در آخر لبه‌ها با فیلتر هدایت‌شده (guided filter) تمیز می‌شن. اگه دوربین تکون خورده باشه، همون فریم خودکار به ماسک اولیه برمی‌گرده.

## سرعت
روی ۲ هسته، هر ۳۸ ثانیه ویدیو حدود ۵ دقیقه طول می‌کشه. بخش‌ها موازی رندر می‌شن، پس روی سرور ۸ هسته‌ای باید چند برابر سریع‌تر باشه.
